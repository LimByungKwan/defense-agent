### 핵심 기능 2
- 기능 이름: 실패를 정직하게 보여 주기
- 제공된 부분: 조회 응답의 실패 표시(값마다 `state: 'unavailable'`과 이유 코드, 전체 실패 시 오류 코드·메시지). 이유 코드 종류는 `src/pc-status.mjs`에서 읽었습니다.
- 내가 직접 개선한 부분:
  - 오류 상자: 최근 측정에 확인 불가가 하나라도 있으면 버튼 바로 아래에 「▲ 읽지 못한 항목 N개」, 항목마다 「○○ 값을 읽지 못했습니다 (이유 코드)」, 이유별 다음 할 일(예: `permission_denied` → 관리자 권한이 필요할 수 있으며 설정은 바꾸지 않음, `timeout` → 잠시 뒤 「다시 조회」 직접). 다음 측정이 모두 성공하면 사라짐
  - 카드: 숫자 대신 「? 확인 불가 · 이유」. 예시 값으로 채우지 않음
  - 그래프: 실패 회차는 0으로 그리지 않고 점선 빈칸
  - 자동 측정 중 전체 실패면 자동 측정을 끄고 다시 시도하지 않음
  - 실패해 잰 시각이 없으면 「잰 시각 없음 (요청 시각)」으로 구별
- 실제 확인 결과: **실제 PC에서는 모든 값이 읽혀 오류 상자가 나오지 않았습니다**(2026-11-15 내 브라우저, 2026-11-12 헤드리스 실측).
- 잘못된 입력이나 연결 실패 때의 동작: **헤드리스 Chrome에 시험용 가짜 응답을 넣어서만 확인했습니다**(2026-11-12, 가짜 응답은 시험 창 안에서만 쓰고 코드에는 없음).
  - 디스크 `permission_denied`·방화벽 `timeout`·Windows 기록 `timeout` → 오류 상자에 3줄과 다음 할 일 2줄
  - 전체 `TIMEOUT` → 「모든 값을 읽지 못했습니다 (TIMEOUT): 서버 응답 시간이 초과됐습니다.」 한 줄, 카드 6개 확인 불가, 「잰 시각 없음 (요청 …)」
  - 네트워크 `query_failed` → 「앱을 껐다 켠 뒤 다시 조회하세요」
  - 모두 성공 → 오류 상자 숨김
  - 자동 측정 중 `TIMEOUT` → 체크가 꺼지고 「조회에 실패해 자동 측정을 멈췄습니다」 표시
  - CPU `invalid_sample` 회차 → 그래프에 점선 빈칸
- 근거: 커밋 `96720b7`, `23d22a8`(확인 불가·빈칸·자동 측정 멈춤), `57697d8`(네트워크·Windows 기록 실패), `44276c0`(오류 상자). 헤드리스 Chrome 가짜 응답 시험 출력·화면(2026-11-12, 저장소에 넣지 않은 임시 기록).

### 핵심 기능 3
- 기능 이름: 회사 서버 연결 요약 (1일차 + 3일차 SDP 카드)
- 제공된 부분: 연결 모드(`connected`·`demo`·`disconnected`·`unknown`), 기기·세션·알림 자료, 연결 없음일 때의 오류(`ENGINE_NOT_CONNECTED`)와 맨 위 빨간 상자. 모두 제공 서버·화면이 만들어 학생 함수에 넘겨 줍니다.
- 내가 직접 개선한 부분:
  - ② 회사 서버 연결 요약 구역: 한눈 요약 카드 4개(SDP 서버(회사 서버)·기기·세션·알림, ● ▲ ? ○ 기호)
  - SDP 서버 카드: 「○ SDP 미연결 (disconnected)」 등. 위 내 PC 조회 결과와 따로 판단
  - 알림 묶기: 같은 코드·메시지 알림을 한 줄로(원문은 「상세 근거」 펼치기에 보존)
  - 로그인 카드(renderIdentity): 「연결 실패」 3번 반복을 「실패 이유 (3곳 → 1줄)」로 묶고 원문은 펼치기에 보존
  - 다음 할 일: 연결 없음은 앱 고장이 아니며 ① 내 PC 추이는 쓸 수 있다는 안내
- 실제 확인 결과: 연결 없음 기본 실행에서 「○ SDP 미연결 (disconnected)」, 「알림 묶음 (원문 5건 → 1줄)」, 「실패 이유 (3곳 → 1줄)」, 다음 할 일이 나오는 것을 확인했습니다(2026-11-12 헤드리스 Chrome, 2026-11-15 run-test 재현 때 내 브라우저에서 ①·② 구조 확인).
- 잘못된 입력이나 연결 실패 때의 동작: 연결 없음 상태 자체가 이 기능의 실제 확인 상태입니다. `demo`·`connected`·`unknown` 모드의 SDP 카드 문구는 헤드리스 시험에서 함수에 모드를 직접 넣어서만 확인했습니다(실제 연결 아님).
- 근거: 커밋 `c651055`(1일차), `65d3dc5`(로그인 카드 요약), `57697d8`(SDP 카드). 헤드리스 Chrome 화면·출력(2026-11-12, 임시 기록).
